# NeWork

NeWork — мой учебный проект для Android. Это небольшая социальная сеть: в приложении можно читать и создавать посты и события, смотреть профили пользователей и добавлять места работы.

## Что умеет приложение

- Показывает ленты постов, событий и список пользователей.
- Позволяет зарегистрироваться и войти в аккаунт.
- Даёт возможность создавать посты и события, ставить отметки «Нравится» и удалять свои публикации.
- Позволяет изменять свои посты и события из меню публикации.
- Позволяет добавлять к публикации ссылку, вложение и место на карте. В посте можно упомянуть пользователей, а в событии — выбрать спикеров и указать формат и дату.
- На странице события можно записаться на него или отменить участие.
- Показывает профиль пользователя: его стену и места работы. В своём профиле можно добавлять и удалять места работы.

Для создания и изменения постов и событий приложение отправляет данные на `POST /api/posts` или `POST /api/events`. При изменении в запросе передаётся ID выбранной публикации.

## Технологии

Приложение написано на Kotlin. Экраны сделаны на XML с View Binding; для переходов используется Jetpack Navigation Component. В проекте также используются MVVM, разделение на слои `data`, `domain` и `ui`, Kotlin Coroutines, Retrofit и Dagger Hilt.

Для вложений используется запрос `POST /api/media`. Поддерживаются изображения, аудио и видео размером до 15 МБ. Для выбора места используется карта MapLibre.

## Как запустить

1. Откройте папку проекта в Android Studio и дождитесь синхронизации Gradle.
2. В корне проекта скопируйте `apikey.properties.example` и назовите копию `apikey.properties`.
3. Откройте `apikey.properties` и вставьте свой ключ после `api.key=`.
4. Запустите приложение на эмуляторе или Android-телефоне.

Приложение обращается к учебному серверу `http://94.228.125.136:8080/`. Методы API описаны в [Swagger](http://94.228.125.136:8080/swagger-ui/index.html).

Файл `apikey.properties` добавлен в `.gitignore`. Не загружайте его в публичный репозиторий: в нём находится ваш ключ API.

## Структура проекта

- `ui` — Activity, Fragment, ViewModel, адаптеры и вспомогательные функции интерфейса.
- `domain` — модели, интерфейс репозитория и use case.
- `data` — Retrofit API, DTO, репозиторий и хранение авторизации.
- `app/src/main/res/layout` — XML-разметка экранов и карточек.
- `app/src/main/res/navigation/nav_graph.xml` — переходы между экранами.

Проект учебный: перед публикацией приложения ключ API нужно хранить на сервере, а не внутри Android-приложения.
